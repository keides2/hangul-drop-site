# 자모 DROP — 한글 낱자 퍼즐 게임

**Language / 言語 / 언어: [English](README.en.md) | [日本語](README.md) | [한국어](README.ko.md)**

**[▶ 게임 플레이](https://keides2.github.io/hangul-drop-site/)** | **[외부 검사: CodeQL / ZAP (경고 12종, 일본어)](INDEPENDENT_SECURITY_CHECKS.md)** | [자체 보안 점검(일본어)](SECURITY_AUDIT.md)

한글의 자음, 모음, 받침을 쌓아 한 글자를 만드는 스마트폰용 낙하형 퍼즐 게임입니다. 별도의 설치나 회원 가입 없이 브라우저에서 플레이할 수 있습니다.

## 처음 시작하는 분을 위한 자음·모음·받침 안내

한글은 **자음(초성)과 모음(중성)을 결합해 한 글자**를 만듭니다. 그 아래에 자음을 더할 수도 있는데, 이 마지막 자음을 **받침(종성)**이라고 합니다.

| 종류 | 게임에 나오는 자모 |
| --- | --- |
| **자음** | ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅅ, ㅇ, ㅈ, ㅋ, ㅎ |
| **모음** | ㅏ, ㅓ, ㅗ, ㅜ, ㅡ, ㅣ |
| **받침(종성)** | ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅅ, ㅇ, ㅈ, ㅋ, ㅎ |

**받침은 별도의 블록 종류가 아닙니다.** 같은 자음을 글자의 맨 아래에 놓았을 때의 이름입니다.

### 먼저 두 자모를 합쳐 보세요

| 자음 + 모음 | 완성된 글자 |
| --- | --- |
| ㅋ + ㅏ | **카** |
| ㄷ + ㅜ | **두** |
| ㅅ + ㅏ | **사** |

모음 **ㅏ·ㅓ·ㅣ는 자음의 오른쪽**, **ㅗ·ㅜ·ㅡ는 자음의 아래쪽**에 놓습니다. 두 자모가 결합하면 **100점**을 얻습니다.

### 익숙해지면 받침을 더해 보세요

| 자음 + 모음 + 받침 | 완성된 글자 |
| --- | --- |
| ㅋ + ㅏ + ㄴ | **칸** |
| ㄷ + ㅜ + ㄱ | **둑** |
| ㅅ + ㅏ + ㄴ | **산** |

두 자모로 글자를 만들면 **다른 블록이 두 번 더 착지할 때까지** 남아 있습니다. 그동안 글자 아래에 받침을 더하면 **200점이 추가**됩니다. 받침을 붙이지 못하면 두 번 착지한 뒤 완성된 글자를 2.3초 동안 보여 주고 지웁니다.

※ 자모의 충돌 및 위치 판정은 게임에 맞게 단순화되어 있습니다.

## 게임 방법

- 자음과 모음을 올바른 위치에 놓아 한 음절을 완성하면 기본 보너스 **+100점**을 받습니다. 서로 충돌하지 않는다면 자음의 빈 공간 안으로 모음이 한 칸 들어가는 배치도 인정합니다. 떨어지는 자모와 NEXT에는 자음/모음 구분을 표시합니다.
- 완성된 두 자모는 **노란빛으로 강조**되고, 다른 블록이 **두 번 더 착지할 때까지** 받침을 기다립니다. 남은 착지 횟수도 화면에 표시됩니다. 그동안 받침을 추가하면 **+200점**을 더 받습니다. 추가하지 않으면 두 번의 착지 후 2.3초 동안 표시한 다음 지워집니다(완성 즉시 2.3초 뒤 자동 삭제하는 방식이 아닙니다).
- 완성된 글자는 지워지기 전에 약 **2.3초** 동안 표시됩니다. 기기의 한국어 음성 합성 기능이 지원되면 발음을 들을 수 있습니다.
- 가로 16칸 중 13칸이 채워지면 줄이 지워지고, 위의 블록이 다시 떨어지면서 연쇄 제거도 가능합니다.
- **NEXT 건너뛰기**는 게임당 세 번 사용할 수 있습니다.

**조작:** 스마트폰에서는 화면 버튼이나 스와이프, PC에서는 방향키 · Space(즉시 떨어뜨리기) · `S`(다음 자모 건너뛰기) · `P`(일시 정지)를 사용합니다. `♪`는 효과음, `🔊`는 한국어 발음 켜기/끄기 버튼입니다.

## 한글 학습에 관한 안내

세로 모음은 초성의 오른쪽, 가로 모음은 초성의 아래쪽, 받침은 글자의 아래쪽에 놓아야 합니다. 다만 게임의 편의성을 위해 약간의 위치 오차를 허용하므로 **표준 한글 맞춤법과 음절 조합 규칙을 완벽하게 재현하는 학습 교재는 아닙니다**.

## 개인정보 보호 및 보안

이 게임은 **하나의 HTML 파일**로 작동하며 외부 JavaScript 라이브러리, 광고 또는 방문자 분석 도구가 포함되어 있지 않습니다. 최고 점수만 브라우저의 `localStorage`에 저장합니다.

공개 소스코드 정적 검사와 로컬 브라우저 실행 검사를 실시했습니다. **검사한 범위**에서는 외부 통신 API, 알려진 인증정보 패턴, 외부 네트워크 요청이 발견되지 않았습니다. 그러나 **제3자 보안 인증이나 절대적인 안전 보장을 의미하지는 않습니다**. GitHub Pages의 접속 기록, 기기의 음성 합성 서비스, 서버의 HTTP 보안 헤더는 별도로 고려해야 합니다.

**CSP 적용 완료:** 정확한 SHA-256 해시가 일치하는 JavaScript와 CSS만 허용하며 불필요한 외부 통신과 승인되지 않은 스크립트를 차단합니다. 게임 조작 및 악성 코드 삽입 차단을 브라우저에서 테스트했습니다. ZAP 재검사 결과는 **PASS 56 / WARN 12종 / FAIL 0**(적용 전: PASS 55 / WARN 13종 / FAIL 0)이지만 클릭재킹 방지 등 경고는 남아 있습니다. **보안이 완벽하다는 증명은 아닙니다.** 자세한 내용은 [외부 도구의 측정 결과(일본어)](INDEPENDENT_SECURITY_CHECKS.md)와 [자체 보안 점검](SECURITY_AUDIT.md)을 참조하세요.

## 소스코드 및 운영

- 게임 주소: <https://keides2.github.io/hangul-drop-site/>
- 소스코드: `index.html` (외부 빌드 도구나 패키지 관리자 불필요)
- 자동 정적 검사: `python3 tests/security_audit.py` / CSP 해시 확인: `python3 tools/csp_hashes.py --check`
- 브라우저 테스트(선택 사항): `python3 tests/browser_security_smoke.py` (Playwright 및 Chromium 필요)
- 이 공개 저장소에는 비공개 개발 저장소의 과거 Git 기록이 포함되어 있지 않습니다.

**라이선스:** 현재 오픈 소스 라이선스를 부여하지 않았습니다. 소스코드가 공개되어 있다는 이유만으로 자유로운 재사용이 허용되는 것은 아닙니다.
