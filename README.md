**[▶ ゲームを遊ぶ](https://keides2.github.io/hangul-drop-site/)** ｜ **[外部検査：CodeQL / ZAP（警告12種類）](INDEPENDENT_SECURITY_CHECKS.md)** ｜ [自己監査](SECURITY_AUDIT.md)

ハングルの字母（子音・母音・パッチム）を積み上げて1文字を作る、スマートフォン対応の落ち物パズルゲームです。ブラウザーだけで遊べます。

## はじめての方へ：子音・母音・パッチム

ハングルは、**子音と母音を組み合わせて1文字**を作ります。さらに、その文字の下に子音を置くこともできます。この最後の子音を**パッチム（終声）**と呼びます。

| 種類 | ゲームに登場する字母 |
| --- | --- |
| **子音** | ㄱ、ㄴ、ㄷ、ㄹ、ㅁ、ㅂ、ㅅ、ㅇ、ㅈ、ㅋ、ㅎ |
| **母音** | ㅏ、ㅓ、ㅗ、ㅜ、ㅡ、ㅣ |
| **パッチム（終声）** | ㄱ、ㄴ、ㄷ、ㄹ、ㅁ、ㅂ、ㅅ、ㅇ、ㅈ、ㅋ、ㅎ |

**パッチムは別の種類のブロックではありません。** 上の子音を1文字の一番下に置いたときの呼び名です。

### まずは2字母で1文字を作ろう

| 子音＋母音 | 完成文字 | 読み方の目安 |
| --- | --- | --- |
| ㅋ ＋ ㅏ | **카** | カ |
| ㄷ ＋ ㅜ | **두** | トゥ |
| ㅅ ＋ ㅏ | **사** | サ |

母音の **ㅏ・ㅓ・ㅣ は子音の右側**、**ㅗ・ㅜ・ㅡ は子音の下側**に置きます。2字母が成立すると **+100点**です。

### 慣れたらパッチムを加えよう

| 子音＋母音＋パッチム | 完成文字 | 読み方の目安 |
| --- | --- | --- |
| ㅋ ＋ ㅏ ＋ ㄴ | **칸** | カン |
| ㄷ ＋ ㅜ ＋ ㄱ | **둑** | トゥク |
| ㅅ ＋ ㅏ ＋ ㄴ | **산** | サン |

2字母が成立した後も、**さらに2回ブロックが着地するまで**文字は残ります。その間に文字の下へパッチムを加えると **追加+200点**。加えられなければ、2回の着地後に完成文字を2.3秒表示して消去します。

※ 読み方のカタカナはあくまで目安です。字母の衝突や位置関係にはゲーム独自の判定があります。

## 遊び方

- 子音と母音を正しい位置に置くと1文字が成立し、基本ボーナス **+100点**。衝突しない場合、子音の空き部分へ母音が**1マス入り込む配置**も判定します。落下中とNEXTの字母には「子音／母音」を表示します。
- 成立した2字母は**黄色系に光り**、次の**2回の着地**までパッチム待ちになります。画面に残り回数を表示し、その間に正しい位置へパッチム（終声）を追加すると **+200点**。2回の着地後は2.3秒表示して消去します（**成立後2.3秒で即消去する仕様ではありません**）。
- 完成した文字は消去前に約**2.3秒**表示され、端末が対応していれば韓国語で読み上げます。
- 横一列が16マス中13マス埋まると消去。消去後の再落下や連鎖もあります。
- **NEXTスキップ**は1ゲーム3回まで使用できます。

**操作：** スマートフォンでは画面上のボタン／スワイプ、PCでは矢印キー・Space（即落下）・`S`（NEXTスキップ）・`P`（一時停止）。`♪` は効果音、`🔊` は韓国語読み上げのON/OFFです。

## ハングル学習について

縦母音は子音の右、横母音は子音の下、パッチムは文字の下に配置する必要があります。ただしゲーム用に多少の位置のずれを許容しており、**正式なハングルの綴字規則を完全に再現する教材ではありません**。

## プライバシーとセキュリティ

ゲーム本体は **HTML 1ファイル**で動作し、外部JavaScriptライブラリ・広告・アクセス解析は組み込まれていません。最高得点だけをブラウザーの `localStorage` に保存します。

公開コードに対して静的検査とローカルブラウザーテストを行いました。**検査した範囲**では外部通信API・既知の認証情報・外部ネットワークリクエストは検出されていません。ただし、**第三者によるセキュリティ認証でも、絶対的な安全性の保証でもありません**。GitHub Pages側のアクセスログ、端末の音声合成サービス、本番HTTPヘッダーは検査範囲が異なります。

**CSP導入済み：** 正しいSHA-256ハッシュを持つJavaScriptとCSSだけを許可し、不要な外部通信と不正なスクリプトを制限しています。ブラウザーのゲーム操作と不正コード挿入の否定試験を実施しました。ZAP再検査では **PASS 56 / WARN 12種類 / FAIL 0**（導入前はPASS 55 / WARN 13種類 / FAIL 0）。ただしクリックジャッキング対策等の警告は残り、**安全性の保証ではありません**。詳細は **[外部ツールの実測結果](INDEPENDENT_SECURITY_CHECKS.md)** と [自己監査](SECURITY_AUDIT.md) を参照してください。
